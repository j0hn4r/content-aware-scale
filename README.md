# Content-Aware Scale

A single-page web app for resizing images with seam carving, the technique behind Photoshop's Content-Aware Scale.

Open `index.html` in a browser — no install or server needed.

- Drag the handles (or use the arrow keys) to shrink or stretch an image up to 2× while keeping important content intact
- **Protect** brush keeps areas from distorting; **Remove** brush makes seams cut through an object first
- **Apply** bakes the result so you can crush an image and then blow it back up with **Scale to original**
- **Show seams** visualises where seams were cut or added; hold **Space** to compare with the original
